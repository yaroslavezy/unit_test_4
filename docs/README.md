# Документация проекта(классическая)

# Общее описание решения
Программа высчитывает площади и периметры круга и квадрата по математическим форумлам:

## Math formulas
### Area
- Circle: S = πR²
- Square: S = a²

### Perimeter
- Circle: P = 2πR
- Square: P = 4a

Для работы с этими функциями, необходимо добавить библиотеку math.

# Описание каждой функции с примерами вызова
## Функция area(r) для круга
```
def area(r):
    return math.pi * r * r
```
Фунция принимает радиус круга, затем считает его площадь по формуле.

Пример вызова функции:
```
area(3)
```
Вывод результа:
```
28.27433388
```
## Функция perimeter(r) для круга
```
def perimeter(r):
    return 2 * math.pi * r
```
Фунция принимает радиус круга, затем считает его периметр по формуле.

Пример вызова функции:
```
perimeter(3)
```
Вывод результа:
```
18.84955592
```
## Функция area(a) для квадрата
```
def area(a):
    return a * a
```
Фунция принимает длину стороны квадрата, затем считает его площадь по формуле.

Пример вызова функции:
```
area(3)
```
Вывод результа:
```
9
```
## Функция perimeter(a) для квадрата
```
def perimeter(r):
    return 4 * a
```
Фунция принимает длину стороны квадрата, затем считает его периметр по формуле.

Пример вызова функции:
```
perimeter(3)
```
Вывод результа:
```
12
```

# Документация проекта(ии)

## 1. Общее описание решения

**Geometric Lib** — библиотека на языке Python для выполнения геометрических вычислений.

Библиотека содержит два модуля:

* `circle.py` — функции для работы с кругом;
* `square.py` — функции для работы с квадратом.

В библиотеке реализованы функции для вычисления площади и периметра геометрических фигур.

---

## 2. Описание функций

### Модуль `circle.py`

#### `area(r)`

Функция принимает радиус круга и возвращает его площадь.

**Параметр:**

* `r` — радиус круга.

**Возвращаемое значение:** площадь круга.

Площадь вычисляется по формуле:

```text
S = π × r²
```

**Пример вызова:**

```python
from geometric_lib.circle import area

result = area(5)
print(result)
```

Результат:

```text
78.53981633974483
```

---

#### `perimeter(r)`

Функция принимает радиус круга и возвращает его периметр.

**Параметр:**

* `r` — радиус круга.

**Возвращаемое значение:** периметр круга.

Периметр вычисляется по формуле:

```text
P = 2 × π × r
```

**Пример вызова:**

```python
from geometric_lib.circle import perimeter

result = perimeter(5)
print(result)
```

Результат:

```text
31.41592653589793
```

---

### Модуль `square.py`

#### `area(a)`

Функция принимает сторону квадрата и возвращает его площадь.

**Параметр:**

* `a` — длина стороны квадрата.

**Возвращаемое значение:** площадь квадрата.

Площадь вычисляется по формуле:

```text
S = a²
```

**Пример вызова:**

```python
from geometric_lib.square import area

result = area(5)
print(result)
```

Результат:

```text
25
```

---

#### `perimeter(a)`

Функция принимает сторону квадрата и возвращает его периметр.

**Параметр:**

* `a` — длина стороны квадрата.

**Возвращаемое значение:** периметр квадрата.

Периметр вычисляется по формуле:

```text
P = 4 × a
```

**Пример вызова:**

```python
from geometric_lib.square import perimeter

result = perimeter(5)
print(result)
```

Результат:

```text
20
```
