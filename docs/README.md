# Документация проекта(классическая)

# Общее описание решения
Программа высчитывает площади и периметры круга и квадрата по математическим форумлам:

## Math formulas
### Area
- Circle: S = πR²
- Square: S = a²

### Perimeter
- Circle: P = 2πR
- Square: P = 4a

Для работы с этими функциями, необходимо добавить библиотеку math.

# Описание каждой функции с примерами вызова
## Функция area(r) для круга
```
def area(r):
    return math.pi * r * r
```
Фунция принимает радиус круга, затем считает его площадь по формуле.

Пример вызова функции:
```
area(3)
```
Вывод результа:
```
28.27433388
```
## Функция perimeter(r) для круга
```
def perimeter(r):
    return 2 * math.pi * r
```
Фунция принимает радиус круга, затем считает его периметр по формуле.

Пример вызова функции:
```
perimeter(3)
```
Вывод результа:
```
18.84955592
```
## Функция area(a) для квадрата
```
def area(a):
    return a * a
```
Фунция принимает длину стороны квадрата, затем считает его площадь по формуле.

Пример вызова функции:
```
area(3)
```
Вывод результа:
```
9
```
## Функция perimeter(a) для квадрата
```
def perimeter(r):
    return 4 * a
```
Фунция принимает длину стороны квадрата, затем считает его периметр по формуле.

Пример вызова функции:
```
perimeter(3)
```
Вывод результа:
```
12
```
